# InCharge Systems Landscape (shared knowledge)

Seed version, pulled from the Accounting knowledge base on 2026-09-28.

| System | Role |
| --- | --- |
| Business Central (BC) | ERP / general ledger. Sales orders, invoices, POs, receipts, payments. |
| Salesforce (SF) | Customers, opportunities, quotes (CPQ), projects, billing opportunities. |
| ServiceMax (SVMX) | Service Work Orders. |
| Procore | EPC project data and budgets. |
| Avalara | Sales tax by zip/product code. |
| PayFabric | Customer card/ACH payments via link (replacing Stripe). |
| RAMP | Corporate card and reimbursements. |
| JotForm | Inbound receiving, vendor onboarding, shipping/commissioning forms. |
| TrustLayer / Compass | Supplier compliance and risk scoring. |
| Drata | IT compliance / policy acknowledgements. |
| InControl | Customer-facing charger platform. |
| ADP | HR system: employee roster and workforce administration. |
| Jira | Work tracking for Digital Product, Software Engineering, QA and UX. |
| Cornerstone LMS | Learning management for Technical Training. |
| Active Directory | User accounts and access, managed by IT. |
| Excel | Spreadsheet analysis and reporting (Business Analytics, Finance). |
| Power BI | Business intelligence: reporting and dashboards. |
| Power Automate / Copilot | Workflow automation and AI assistance in Microsoft 365. |

For the fuller narrative (who owns what, known gaps, open questions), see
