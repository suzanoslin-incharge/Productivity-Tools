# Filename standard

Applies to every file and folder in the knowledge base (`_KB`).

- **No spaces.** Ever.
- **Hyphen (`-`)** joins the words of one phrase: `Business-Plan`.
- **Underscore (`_`)** separates distinct elements: `Business-Plan_Writer`.
- **Capitalization is flexible.** Capitalized words (`Business-Plan`) or camel
  case (`businessPlan`) are both fine; the only hard rule is no spaces. Keep
  system and acronym spellings exact (`Business-Central`, `SF`, `O2C`).
- **Dates are ISO**, `YYYY-MM-DD`, always the last element.
- Keep the original extension in lowercase.

| Item | Pattern | Example |
| --- | --- | --- |
| Source folder | `Source-Name_YYYY-MM-DD` | `Otovo-Integration-Discovery_2026-09-28` |
| Article file | `System-or-Product_Process-or-Topic.md` (mirrors the Title rule) | `Business-Central_Inbound-Receiving-and-Put-Away.md` |
| Reference stub | same as an article, named for the outside document | `Procure-to-Pay_Process-Description.md` |
| Fixed files in a source folder | by source type | `Source-Metadata.md`, `Transcript.md`, `Recording-Link.md` |
| Recordings and scans | `Source-Name_YYYY-MM-DD.ext` | `Sales-BC-to-SF-Integration_2026-09-25.mp4` |
| Category folders | `Business-Function/Process-Area` | `Operations/Warehouse-and-Inventory-Management` |
| Special folders and files | leading underscore | `_Templates`, `_Taxonomy.md`, `_Superseded-Archived` |

The SOP (Step 2) names meeting folders `YYYY-MM-DD Meeting Title` (date first,
with spaces). This standard deliberately overrides that: name first, no spaces.
Folders sort by name, not chronologically.
